# 账户演示对象

library/scenes/AccountObjects.tsx 为本账号原创SVG演示部件。导出 Slip（基金或持仓凭证）、Tray（资产托盘）、CashBox（现金回款）、Phone（明确写着假设账户的示意界面）及 Balance（投入与资产对照）。

只负责展示调用者给定的值，不计算实际基金收益，不连接券商，不暗示任何实际成交。Slip的price可表示购入价格或当前市值，必须同时设置正确label/caption，不能将现值标成购入价。Phone的total须由调用者核对是否包含cash，不自动计算；shares不包含已卖出的份额。回款金额不作为额外盈利重复相加。

坐标按1080宽画面；调用者重新设计动作路径和口播时间。凭证不能移到手机数字文字上方；在托盘内操作时保持标签与文字分区。依赖同库theme，无照片和外部网络。组件不包含任何私人账户。本期假设数据和完整分镜不属于通用组件。

已做类型检查和本期实际渲染，预览见account-objects-preview.png。抽帧不等于全片正常速度听看。
