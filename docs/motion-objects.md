# 资金与生活情境动画组件

`library/scenes/MotionObjects.tsx` 是本账号原创的SVG对象库。依赖Remotion和同库theme，不含第三方照片。

- Money / Coin / Tag：纸币、概念金币、价签；数字由调用者传入。
- Stream：纸币按顺序沿抛物线移交，from/to为端点，start/end限制动作区间。n不是实际金额，不能用流动纸币数量伪装精确账户数据。
- Factory：工厂、传送带、利润标签和受损状态，适合假设企业盈利机制。不是实际工厂或某家上市公司。
- Calendar / Receipt / Wallet：日历翻页、账单和钱包。翻页数字只是时间流逝示意，不冒充真实日期。
- Chart：给定形状的示意路径，duration控制画线时长，up控制方向；不是真实逐日行情。
- Photo：调用项目自己准备的本地图片与作者署名，文件不随库附送；每图本片仅一个连续区间。
- Desk：桌面道具，供批准的人物形象另行布局。

以上组件使用1080宽坐标。调用者须重新检查字幕安全区和所有动作峰值。物件的组合、时序和口播对齐由本期分镜决定，不能机械复制整片。账单默认高260，相邻账单须留间距或缩放，不能遮住前一张的金额。工厂利润变化与价签、比率必须同源计算，不能出现算式20倍而表盘仍16倍的矛盾。

本期已做实际渲染与多时点截图检查；抽帧不等于完整正常速度审片。预览见motion-objects-preview.png。
