# 公开参考怎样用在潘哥的片子里

供编导需要换一种讲法时查阅。这里只记录能在公开材料中核对的做法，借鉴点是本项目自己的剪辑判断。

| 材料 | 可直接核对的内容 | 潘哥这边怎么试 |
| --- | --- | --- |
| [老高与小茉《曼德拉效应，是谁动了我的记忆》](https://www.youtube.com/watch?v=5x9mNMnG9lY) | 作品说明从观众自己的记忆发问，并列出相关旧作和题材播放列表 | 让没有买过股票的人也能代入第一道题。结尾只荐一部能回答紧接着那个疑问的作品 |
| [曼萨财经《万字解析雷曼兄弟崩盘始末》](https://www.douyin.com/video/7542729955688467752) | 作者在作品介绍中把时间收在最后 48 小时，同一事件由监管者、公司、财团三个位置展开 | 长片先选清楚观众跟谁走。切到另一个人时，交代他手里掌握了前一个人缺的什么 |
| [3Blue1Brown《线性变换与矩阵》](https://www.3blue1brown.com/lessons/linear-transformations/) | 图文版将向量从起点移到终点，再给网格留下原来的参照，读者能亲眼对照变化 | 稀释股权、借款回撤、算力成本也可以保留参照物，让人一眼看到谁的那一份变了 |
| [Remotion 官方制作 skill](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-markup/SKILL.md) 与[字幕 skill](https://github.com/remotion-dev/remotion/tree/main/packages/skills/skills/remotion-captions) | 把镜头时序和带时间的字幕作为可以单独调整的材料 | 先定一次动作的发生点，再对齐到实际声音；镜头改长短时保留完整轮次和已核对的字幕 |
| [YouTube 官方留存报告说明](https://support.google.com/youtube/answer/9314415?hl=zh-Hans) | 单片曲线可定位重复观看和跳过的时间。回看可能因有趣，也可能因没讲清 | 回到那个时间点看具体台词和画面，再用下一条的一个改动验证猜测 |

前两项依据作者公开标题、介绍及相关作品入口。这里没有据此推断他们的具体接话秒数、逐镜节奏、全平台播放排名或创作配方。外部代码、主持人音色、原视频和插画均未打包。做长片时可以学习题材如何展开，竖屏前几秒仍用本账号自己的作品检验。
