# 审查与交付

## 机器检查能做的

- `audit_episode.py`：时序连续、字幕范围、文字清理、角色说话人、同一照片出场区间、镜头ID和来源记录。
- `check_repository.py`：便携路径、索引文件存在/哈希、异常大文件、素材重复、文档链接。
- `verify_export.py`：视频/音频流、尺寸、帧率、时长和完整解码。
- `contact_sheet.py`：出每镜前/中/末抽帧与检查图；它不是运动流畅度评分。

## 必须由实际画面确认的

1. 首帧大字与话题主体清晰，封面不静态停太久。
2. 双人介绍同框，视线按对象切换；讲话/倾听/停顿口型正确。
3. 全运动路径、伸手峰值和过渡中无文字压人物/图形；字幕独立居中。
4. 抖音搜索、右侧按钮、底部描述模拟遮罩下可读；检查其他平台裁切。
5. 正常速度播放代表性的开场、复杂机制、交接与结尾，听名字、读数、尾字、音效和音乐。需要完整审片时实际看完整片。
6. 不重复照片或完整画面；不能靠同一镜头换文字填时长。逐段检查是否只有字幕在变化，是否只有入场动画，数字变化的结果是否在相应口播说出时到位。检查转场前后物件状态和视线，而非仅统计切镜次数。
7. 时效事实和示例边界正确，收入/利润、邀请/交付等不偷换。

审片报告记录 **看了哪些时间段、抽了哪些帧、是否听音、哪些未验证**。不能把通过脚本、编译、导出或抽帧写成“全片正常速度听看通过”。未做的项目标未做，不编造绿色分数。

## 交付包

MP4、从成片真实首帧导出的封面、文稿、SRT、资料来源/示例假设、直接可发布的标题描述和话题标签。可附本期速查表。不要只给开发源码，也不要要求用户自己拼接音画。

新组件以实际渲染、必要前中末截图和已知限制入库。质量可复现的基础是资产、依赖、分镜与审片共同保留，不是一句“保证爆款”。

交付前与近期成片联系图比较跨期场景与动作重复；保留品牌身份，检查是否只是同一镜头换词、换背景。该比较是创作检查，不能推断平台内部识别权重或保证审核通过。

## 一版值得往下做的开场

从成片开头一直试到**第一个问题得到回答**，再决定开场是否成立。比较两版时把立场问题问具体，如“刚换工作的是创始人还是产品团队？哪句让你明白的？”让第一次接触素材的读者先复述，再看是否愿意知道后面的原因。没有实际观众时可做独立审稿，把误读记为线索，不写成用户测试结果。试听版可以很短，正式节目自由决定长度。

拎出最需要反应的一句，保留前一句的尾音与下一句的起音，正常速度连听。先只听声音，分辨听者是在抢答、消化，还是准备反驳；再静音播放重要的动作，看看旁观者能否指认谁动了什么、留下了什么。最后合起来检查动作是否发生在词说出口的那一拍。记录实际听看范围。做语气对照时用同文本同声线；如果同时重写台词、换配乐，只记录整体偏好。核定过的参考片可以留在私人工程备查。

## 收到后台数据时

用最终导出的 SRT 定位第一次点名、第一次给出处、解释说完、或留存曲线明显掉下去的时刻。在编辑记录里写下当时的台词和动作。命令输出的是字幕显示区间，讲完整个答案往往要读到下一句；转场和留白可能没有字幕。

```bash
python3 scripts/cut_notes.py episode/outputs/captions.srt --line '凯特吴' --line '合并' --at 18.5
```

| 想检验什么 | 看哪项 | 回到片子改哪里 |
| --- | --- | --- |
| 点进来很快就走 | 同平台同发布龄的单片 2 秒跳出、5 秒留存，及可得的前 30 秒曲线 | 对照标题承诺与第一份实质答案，看自我介绍或复述是否挡在前面 |
| 看了一段，中途失去线索 | 对齐中段掉点、跳看或回看附近的台词，兼看时长相近的作品 | 专名密集、比较基准换了、或只剩人念图卡？每次选一个解释再改。回看也可能是没看懂 |
| 看完是否想留、想再看一集 | 每千播放收藏、分享、评论、作品归因新增关注。平台提供时另看相关作品或片尾元素点击、回访观众 | 收藏提示更适合放在判断方法刚用完时。连看要检查推荐的旧作是否真的回答了新问题 |

把本期、上期都拉到发布后相同时间，例如各自发布后 48 小时，保留播放分母和指标来源。每千次 = 单片该项次数 ÷ 同窗口播放数 × 1000。零分母、缺字段、时间窗口不同都不填可比差值。抖音与 YouTube 的播放口径分别记录；账号净增粉不能替代作品归因新增关注。回访与关联点击各有自己的分母，也不能单独证明同一人连续看了两集。

留一条可以被数据推翻的判断。例如“如果早段复述拖慢了进入故事的速度，删掉复述后，同题材作品的早段留存应有改善；若掉点仍集中在英文人名处，下一次先试角色介绍”。20 秒内给出首份答案可以当一次实验。顺剪与重剪都可私下比较，公开试验只发布完成的作品。没有同龄数据时记录待观察，不编留存数。
